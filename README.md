# Uploader Ultra Plus 🚀

A mobile-first content operations and social publishing platform for BIGDAWG and The Curiosity Hub.

## Status
**Early development, NOT connected to live publishing.**

## Goals
- One simple interface for captions, graphics, videos, approvals, and a content queue
- Free-first self-hosted publishing when properly authorized
- Facebook Pages first, then YouTube, Instagram, and TikTok
- Verify video duration ≥60 seconds, actual narration, and rights before publishing
- Distinguish drafts, scheduled items, submissions, confirmed live posts, and failures
- Keep account tokens out of GitHub source code

## Safety
No passwords, access tokens, secrets, or personal information should be committed into this repository.
This repository is currently public. Switch its visibility to **Private** in Settings if you want to keep the source confidential.

## Next build
